**App Name:** Foodie  

**Description:** Foodie is a Smart Pantry Manager that gives users recipes directly based on what they currently have in their kitchen to reduce food waste.

**Database chosen:** SQLite.

I chose SQLite because it was the simpler and more lightweight option. At first I didn't realise it was built in and wanted to use MySQL because I had used it in a previous assignment and it had been some time since I used SQLite. However I didn't need MySQL because what I was doing was far simpler and didn't need the complexities of MySQL. Since my app does not require any cloud based services or internet connection, using a built-in option that stored the data locally was the more natural and better option for me.

**Prerequisites**
Android Studio - Quail 2 or newer
Java Development Kit version 25 or newer
Android min SDK: 26
Android Target SDK: 36
Compile SDK: 36

**Set-Up Guidelines**

**Step 1:** Open Android Studio

**Step 2:** Select the **Open** option, either on the welcome screen or under **File** and select the project's root folder **Foodie** and click **OK**

**Step 3:** Allow Android Studio Built to automatically sync and if prompted, click **Trust Project**

As the local.properties file has been removed from the project folder, Android Studio will automatically generate the file on the first successful sync.

**Step 4:** If not triggered automatically, click **Sync Project with Gradle Files** to generate the necessary build and cache files.

**Step 5:** Click **Build > Make Project** or Launch the app on an emulator/physical device
